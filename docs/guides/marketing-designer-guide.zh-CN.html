01

“我现在做得也挺好，为什么换？”

先看任务。Design Agent 的主要价值，出现在同一主题要做成多种素材、遵守品牌、反复修改并最终交付的时候。

下面用一个假设任务比较：为公司参展，制作一张主海报、三种社媒尺寸、一份服务介绍和一条 30 秒视频。所有示意均为虚构，不代表真实客户案例或效果数据。
手工、文生视频、Codex 与 Design Agent 的适合场景比较
工作方式它很适合什么放到这次展会任务里怎么选择
手工设计
与专业软件		高要求主视觉、精细修图、自由创作和细节控制。你可以全程掌控，也需要自己推进尺寸适配、排版、剪辑和逐项检查。已有成熟模板，或只做一张要求很高的主视觉时，继续手工很合理。
Text-to-video
视频生成模型		生成有氛围的镜头、场景和创意视觉，具体能力因模型而异。生成镜头后，仍常需要组织品牌文字、真实产品画面、节奏、声音和其他平面物料。核心需求是“生成一个镜头”时，可直接用视频模型；素材合适时再交给后续流程编排。
Codex 等
通用编程助手		按要求写脚本、网页或演示稿；配好工具和规范后也能完成复杂制作。可以做这套任务；具体的品牌约束、制作工具、检查方式和交付格式，需要在工作环境中明确。已有顺手的提示词、模板和流程时，继续用它；通用助手的能力取决于你给它的配置。
Design Agent围绕品牌素材制作，把简报、设计、渲染、检查和交付组织为专门流程。围绕同一简报调用技能，制作各类文件，并在修改时参照品牌与原始要求。同主题、多格式、常修改、需协作的任务，值得试用。最终效果取决于资料、配置与审阅。

“我手工做得很好。
它会不会反而增加沟通？”

会有这种可能，尤其是需求尚不明确、你对细节已有精确想法时。可以先把尺寸延展、常规排版、资料转图表、字幕与导出交给它，把主视觉和关键细修留在自己的工作台。先用一个低风险任务试协作是否顺手。

“文生视频已经很惊艳，
这里的视频有何价值？”

看你要的是哪种视频。市场工作还常要求准确的功能名称、真实截图、正式 Logo、可读字幕、明确时长和后续改稿。这里的工作流擅长组织这些信息。它主要制作信息动画、图形运动和素材编排；电影感镜头仍可由你选用的视频模型或拍摄提供。

“Codex 做 PPT 很简单，
是不是已经够用了？”

只需要一份演示稿，而且结果已经满意，那就够用。Design Agent 值得比较的是整套营销素材的制作流程是否省心：品牌资料是否复用、不同文件是否统一、改稿是否保留要求、交付前是否检查。这里的演示交付以 PDF 或网页演示为主，不默认承诺 PPTX。如果必须原生编辑 PowerPoint，先确认格式。

02

它把哪些常见工作接了起来？

技能像一套制作手册，工具负责实际出图与出片。一次任务按需要组合使用，你只需描述目标和反馈。

品牌延续到每份物料

从团队确认的品牌包读取颜色、字体、Logo 与语气。海报、图表和视频共享依据，减少每次重新解释。

一个主题，多种交付

同一信息可以进入静态图、PDF、网页演示或视频流程。不同尺寸重新排版，横竖屏需要各自检查。

制作后还有检查

工具检查尺寸、字体及部分布局问题；视觉模型可用时再查看真实画面。业务事实与最终发布由人审核。

同一个展会任务，可以这样往前走

01 / 你给资料

目标与事实

展会信息、服务卖点、Logo、截图和使用场景。

02 / 先定方向

简报与样稿

核对必备信息、缺项和交付规格。视频先看分镜。

03 / 制作延展

成套物料

围绕同一主题，分别制作海报、图表、演示与视频。

04 / 一起改稿

明确改哪里

用具体反馈迭代；涉及哪些版本要说清楚。

05 / 检查交付

文件与验收

拿到预览和成品，核对事实、视觉、播放与格式。

这是协作流程示意。不能保证一句修改自动同步所有文件；请明确“哪些物料都要改”，并逐项验收。

03

从你手头的六种任务开始

每次都想清楚三个问题：我有什么？我想让观众记住什么？最后要拿到什么文件？

产品上新 / 社媒海报

准备：已确认标题、卖点、真实截图和尺寸清单。

得到：一组重新排版的图片；可按反馈统一调整标题或视觉重点。

主要技能：content-brief → brand-design → stills → visual-verify

展会 / 活动成套宣传

准备：准确日期地点、展位信息、品牌、各媒介尺寸与文案。

得到：按约定制作的预告图、服务介绍和大屏视频等物料。

主要技能：media-production → stills / slideshow / launch-film

服务方案 / 数据讲解

准备：服务流程、真实数据与来源，或销售讲解大纲。

得到：清晰的流程图、图表、数字卡和介绍 PDF 或网页演示。

主要技能：data-viz + stills / slideshow

产品演示 / 功能动图

准备：真实录屏或截图，指定重点、可删内容和需遮挡的信息。

得到：截图讲解片，或从真实录屏剪出的操作演示 / GIF。

主要技能：general-video + hyperframes-keyframes / gif-edit

讲解视频 / 课程封面

准备：单主体讲话视频、词表、逐字稿；封面用真实照片或截图。

得到：字幕视频、封面候选和缩小预览；转写需先确认可用。

主要技能：embedded-captions + thumbnails + visual-verify

发布片 / 品牌内容

准备：产品简报、真实素材、参考片、目标时长及声音要求。

得到：参考分析、分镜、阶段预览，再按确认方向制作视频。

主要技能：reference-study → storyboard → launch-film + sound

上图是帮助理解交付类型的示意，不是 Agent 实际产出的展示作品。展会印刷大幅物料还需提前确认成品尺寸、分辨率、出血与印厂要求。

事实与素材

真实内容，由你把关

产品功能、服务承诺、数据、客户案例和活动信息要有来源。连续操作演示需要真实录屏；截图只能讲解已有界面。已授权的照片、录像和音轨可以直接提供。

格式与后续编辑

先说清最终怎么用

常见交付包括图片、SVG、PDF、MP4、GIF 与网页演示或制作源文件。不默认提供 PPTX、PSD 或 AE 工程；有必须使用的编辑软件或印刷要求时，先确认格式与交接方式。

环境与费用

有技能，不等于服务已开通

生图、配音、音乐、音效、转写、外部素材库及 Paper 都有配置条件。需要付费生成时先确认；没有外部服务时，可使用已有素材，或先制作无声预览。

审稿与发布

拿到文件后，再决定发布

自动检查可发现一部分技术问题，审美、事实、商用权限和传播效果仍需人判断。交付文件不等于已发布；投放效果也不能由封面或视频预览来保证。

先用一次真实任务，判断它是否适合你。

选一份已做过的海报，要求改成两种尺寸，再加一张同主题讲解图。比较从发需求到拿到可用文件的总时间、你需要介入的修改次数，以及结果是否符合品牌。它是否值得加入工作流，要靠这次协作来判断。
